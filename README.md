# Kids Zoo Quiz

A browser-based educational animal quiz built with plain HTML, CSS, and JavaScript.

## Features

- 20-question animal knowledge bank
- 10 randomized questions per game
- Score and streak system
- Immediate answer feedback
- Educational animal facts
- Responsive desktop/mobile layout
- Number-key shortcuts (1–4)
- No external frameworks or build step

## Portfolio description

An educational browser quiz for children featuring randomized animal questions, scoring, streaks, and short facts after each answer. Built with HTML, CSS, and JavaScript.
